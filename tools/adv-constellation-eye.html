星座與眼圖實驗室

超出考照範圍的工程級主題：高階數位調變（16QAM）、雜訊／I-Q 不平衡／相位噪聲如何讓星座點「糊掉」，以及眼圖怎麼一眼看出符號間干擾（ISI）。先學過基礎「星座圖 IQ」分頁再來這裡。

星座圖是接收端的「健康儀表」：理想時每個符號落在固定點；一旦有雜訊、I-Q 增益/相位不平衡、相位噪聲，點就會擴散、旋轉或變形。點之間還分得開 → 還能正確判別；糊成一團 → 誤碼。眼圖則把時域疊起來，「眼睛」張得越開＝ISI 越小、越好解。
調變階數
雜訊（降低 SNR） 20 dB
SNR 越低，點雲越散
I/Q 增益不平衡 0 %
I、Q 兩路增益不一致 → 星座被拉成橢圓
I/Q 相位不平衡 0°
兩路非正交 → 星座被「剪切」歪斜
相位噪聲 0°rms
本振不純 → 星座點沿圓周「抹開」

眼圖（I 通道，疊多個符號）
實驗挑戰：切到 16-QAM，先只加雜訊把 SNR 降到約 12dB，看哪一圈的點先開始互相侵入（外圈還是內圈？）。再把雜訊歸零、只加「相位噪聲」，觀察星座點是沿半徑散還是沿圓周散——這對應本振哪種缺陷？用 1–2 句寫下你的判讀。
為什麼這在進階軌
16QAM、I-Q 校正、相位噪聲、眼圖/ISI 屬於通訊系統與 SDR 工程範疇，不在 NCC 業餘考照範圍，也跟民防語音通聯無直接關係。放這裡給想往工程/SDR 深入的人。基礎請回 調變視覺化・星座圖 IQ。
