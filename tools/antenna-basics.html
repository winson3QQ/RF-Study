那要多長？先算波長，再取一段
電波一個完整起伏的長度叫波長 λ，用 λ(公尺) = 300 ÷ 頻率(MHz) 算。
天線常取波長的「一段」來共振：半波偶極取 λ/2、四分之一波長垂直取 λ/4。實際做出來，因為「端點效應」會比理論再短約 5%（速度因數 ≈ 0.95）。

這兩種長度長什麼樣子？
常見業餘頻段天線長度
頻段頻率λ/2 偶極（實體）λ/4 垂直（實體）
考試重點：頻率越高、波長越短、天線越短。145MHz 的 λ/4 約 49cm，所以 2m 手持機天線很短；7MHz 的 λ/2 偶極長達約 20 公尺。電線長度公式也常考英制：λ/2 偶極(英尺) ≈ 468 ÷ f(MHz)。
dBi 還是 dBd — 差別只在「跟誰比」
dBi
以等向性天線（Isotropic，向所有方向均等輻射的理想點源）為基準。現實中不存在，是純理論參考。
0 dBi = 等向性天線
dBd
以半波偶極天線（Dipole）為基準。最常見的實際參考天線，工程現場常用。
0 dBd = 半波偶極天線
dBi = dBd + 2.15 dB  |  dBd = dBi − 2.15 dB

考試陷阱：同一支天線用 dBi 標示時，數字會比 dBd 大 2.15。廠商廣告愛用 dBi，讓增益看起來更漂亮。天線是被動元件，「增益」是把能量集中到某方向，不是憑空放大功率。

八木（Yagi）靠後面的反射器＋前面的導向器把能量往前推：元素越多 → 主瓣越窄、增益越高、前後比越大（越能無視後方干擾），但也越需要「轉動對準」對方。「波束寬度」就是主瓣強度掉到一半（−3dB）時張開的角度。
＊圖是「從天線側面看」的相對強弱：最外圈＝最強，往內每圈代表變弱。嚴格講還分「水平面／垂直面」兩張圖，這裡先抓整體形狀的直覺。
極化：電波「擺動的方向」
垂直極化
天線跟地面垂直（站直）。手持機、車機、中繼台幾乎都用它。
水平極化
天線跟地面平行（躺平）。HF 的 SSB／CW、八木打 DX 常用。
圓極化
擺動方向邊轉邊前進。衛星通訊常用，比較不怕訊號忽強忽弱。

考試重點：收發兩端極化要一致。垂直對水平（交叉極化）損失 20 dB 以上，幾乎收不到——把手持機天線立直，就是為了對上中繼台的垂直極化。

饋線與匹配（往下一站）
天線把電變成電磁波，但要先讓天線阻抗與饋線特性阻抗（通常 50Ω）匹配，否則能量會反射回來形成駐波（SWR）。
