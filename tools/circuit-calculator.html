PEP 峰值波封功率 / RMS
關鍵公式
PEP = V_peak² / (2 × R)  |  V_rms = V_peak / √2 ≈ V_peak × 0.707
示波器測峰對峰值 Vpp → Vpeak = Vpp/2 → PEP = (Vpp/2)² / (2×R)
考試最常考： 示波器在 50Ω 假負載測得 Vpp，求 PEP。公式：PEP = (Vpp)² / (8 × 50)
