dBi vs dBd — 天線增益基準
dBi
以等向性天線（Isotropic，向所有方向均等輻射）為基準。理論上的完美全向天線，現實中不存在。
0 dBi = 等向性天線增益
dBd
以半波偶極天線（Dipole）為基準。最常見的實際天線，工程師常用此基準。
0 dBd = 半波偶極天線增益
dBi = dBd + 2.15 dB  |  dBd = dBi − 2.15 dB
