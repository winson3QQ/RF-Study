OFDM 子載波視覺化

OFDM 把一條高速資料拆成許多互相正交的低速子載波並排傳送，是 Wi-Fi／4G／5G／DVB 的核心。這裡看子載波如何在頻域「峰對零」彼此不干擾，以及子載波數對符號時間的影響。

關鍵字「正交」：每個子載波的頻譜是 sinc 形，每個子載波的峰值剛好落在其他子載波的零點，所以即使彼此重疊也不互相干擾——這讓 OFDM 頻譜利用率極高。代價：對頻率偏移與相位噪聲敏感（會破壞正交性）。
子載波數 N 8
N 越多 → 每個子載波越窄、符號時間越長 → 越抗多徑（但越怕頻偏）
頻域：各子載波 sinc 峰值對齊其他子載波零點（正交）
時域：N 個子載波相加 = OFDM 符號
實驗挑戰：把 N 從 4 加到 32，觀察頻域圖中每個子載波「峰對零」的關係是否一直成立，以及時域波形的複雜度怎麼變。想一想：為什麼子載波多 → 符號時間長 → 對多徑（延遲擴展）更耐受？
