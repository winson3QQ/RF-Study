二等業餘無線電 — 輔助學習工具

14 tools
TOOL · 鏈路預算

Link Budget 鏈路預算模擬器

發射→天線→路徑損耗→接收一條鏈路走完，即時看接收功率與餘裕（Fade Margin）夠不夠通。

 TOOL · 接收機鏈路

接收機 NF / MDS 串接計算器

串接 LNA／混波器／IF，算總增益、總 NF、MDS 與 SFDR，指出瓶頸級——親手感覺 NF 與線性度的取捨。

 TOOL · 傳播多徑

傳播與多徑視覺化

雙射線（直射＋地面反射）＋菲涅耳區，看天線高度／距離／頻率如何造成多徑衰落與地形阻擋。

 TOOL · 頻譜

業餘頻段互動頻譜

視覺化瀏覽台灣業餘無線電各頻段分配，互動查詢頻率範圍與用途。

 TOOL · 調變

調變方式視覺化

AM、FM、SSB、CW 等調變方式的波形動態比較，理解訊號本質。

 TOOL · 電路

電路計算互動工具

歐姆定律、功率、阻抗計算，備考實用，輸入參數即時得出結果。

 TOOL · 呼號

台灣業餘電台呼號解碼器

輸入呼號自動解析地區、等級與類型，搭配地圖視覺化顯示電台位置。

 TOOL · 傳播

電離層傳播互動視覺化

拖動頻率／仰角／時間，看天波訊號如何被電離層反射，理解 MUF、跳躍距離與 NVIS。

 TOOL · Q簡語

Q 簡語情境訓練

在對話情境中學 Q 碼，搭配閃卡、速查與易混淆配對，不只是死背代碼。

 TOOL · 接收機

超外差接收機互動解析

點擊方塊圖各級看功能，附本振／中頻／鏡像頻率計算，與 SWR、dBi／dBd 計算機。

 TOOL · 駐波

SWR 駐波互動視覺化

動畫呈現入射波、反射波與駐波，拖動阻抗看 SWR、反射係數與功率反射比即時變化。

 TOOL · 干擾診斷

干擾診斷互動流程圖

從症狀一步步問診找出干擾原因與解法，附聲音辨識、概念速查與 EMC 考題。

 TOOL · 安全防護

RF 安全防護互動工具

拖動功率／增益／工作週期看 RF 曝露安全距離，附工作週期、電氣安全速查與全 26 題。

 TOOL · 電源電路

電源電路互動圖解

整流電路圖＋動態波形、二極體／電容／電晶體元件辨識，與系統原理電源題速查。
