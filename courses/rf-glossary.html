RF 無線電術語白話手冊

給沒學過 RF 理論的你 — 不用公式，用比喻和圖解理解每個術語。查了就懂，隨時翻閱。

基礎概念：先搞懂這些，其他就通了
無線電頻率 / 頻道
Radio Frequency / Channel
無線電信號在空氣中以「波」的形式傳播，每個波每秒振動的次數就是頻率，單位是 Hz（赫茲）。
生活比喻就像廣播電台一樣，「台北廣播 FM 98.1」就是在 98.1MHz 這個頻率上。你把對講機「調到 145.500MHz」，就是在聽那個頻率上的對話，就像調廣播電台。
常見頻率範圍： VHF 144–148 MHz → 對講機常用（如145.500） UHF 430–440 MHz → 手持對講機常用（如433.500） FM廣播 87.5–108 MHz → 收音機 頻率越高 → 波越短 → 穿透力越弱但帶寬越大
記憶方法頻率就是「電台號碼」，兩台對講機要通話，電台號碼必須一樣。
基礎情境1
〰️
波長
Wavelength (λ)
一個完整無線電波的「長度」，單位是公尺或公分。頻率越高，波長越短。
生活比喻把無線電波想成水波紋。你快速揮手（高頻），水波紋密集、每個波紋很短。你慢慢揮手（低頻），波紋稀疏、每個波紋很長。
計算公式（這個夠簡單，記住吧）： 波長(公尺) = 300 ÷ 頻率(MHz) 145MHz → 300 ÷ 145 ≈ 2.07公尺（波長2公尺） 435MHz → 300 ÷ 435 ≈ 0.69公尺（波長69公分） 這直接決定天線該做多長！
記憶方法頻率 × 波長 = 300（光速的簡化）。145MHz 的對講機，天線長約 52 公分（波長的四分之一）。
基礎情境5
FM 調制
Frequency Modulation
FM 是「調頻」的縮寫。把聲音「藏進」無線電波的一種方式。對講機和廣播電台都用 FM。
生活比喻想像你講話時聲音忽高忽低，FM 就是把這個「高低起伏」轉換成電波頻率的「快慢變化」。收音機再把「快慢變化」還原成聲音。就像摩斯密碼，但編碼規則不同。
AM（調幅）：改變波的「高度（振幅）」來藏信息 ─波波波─ → ───波─波波──── FM（調頻）：改變波的「密度（頻率）」來藏信息 密─稀─密 → 聲音的高低起伏 FM的優點： ✓ 抗干擾（捕捉效應） ✓ 音質較AM清晰 ✓ 民防對講機的標準
記憶方法FM 廣播和對講機的原理一樣。你每天聽的台北 FM 電台就是 FM 調制！
基礎
信號強度 / S值
Signal Strength / S-meter
接收到的信號有多強，用 S1 到 S9 表示，S9 最強。通訊報告時說「你的信號是五九」，意思就是 S5 S9 的最高值，信號很強。
生活比喻就像手機的格數。1格=S3，2格=S5，3格=S7，4格=S9。格數越多，訊號越強，通話越清晰。
S值對照表： S1 ────── 幾乎聽不到（-121dBm） S3 ──────── 很弱（-115dBm） S5 ─────────── 勉強可聽（-109dBm） S7 ──────────────── 中等清晰（-103dBm） S9 ──────────────────── 很強（-97dBm） 每增加1個S值 ≈ 信號強度增加6dB（約4倍功率）
記憶方法「五九報告」是無線電通訊裡說對方信號最完美的方式，就像給 5 顆星的評價！
基礎
功率 / dBm
Power / dBm
功率是信號有多「用力」發射，單位是瓦（W）。dBm 是另一種表示方式，更方便計算弱信號。
生活比喻瓦特就像燈泡的亮度。1W 對講機就是 1 瓦的燈泡，5W 就是 5 瓦，更亮（更遠）。dBm 就像把亮度轉換成「刻度」，讓你更容易比較非常暗到非常亮的範圍。
常用換算（記幾個就夠）： 1W = 30 dBm （對講機低功率） 5W = 37 dBm （對講機標準功率） 10W = 40 dBm （車載台） 25W = 44 dBm （基地台） 接收信號（非常弱）： -90 dBm ≈ 0.000000001W（還是能通話） -120 dBm = 接近靈敏度極限 dBm每增加3 = 功率約加倍 dBm每增加10 = 功率增加10倍
常見誤解很多人以為功率大就一定能通話。錯！天線方向、地形、頻率都影響更大。
基礎
VHF / UHF
Very High / Ultra High Frequency
兩種不同的頻率範圍，決定無線電信號的「個性」：能傳多遠、能不能穿牆、天線要多長。
生活比喻VHF 像「長跑選手」，跑得遠但體型大（天線長）。UHF 像「城市跑者」，更靈活能在建築物間穿梭，但跑不那麼遠。
VHF（30–300MHz，台灣民防常用144–148MHz） ├─ 波長：1–10公尺 ├─ 天線長：約51公分（144MHz的λ/4） ├─ 特性：傳播遠、但建築物穿透差 └─ 用途：山地搜救、長距離通聯 UHF（300–3000MHz，台灣民防常用430–440MHz） ├─ 波長：10公分–1公尺 ├─ 天線長：約17公分（435MHz的λ/4） ├─ 特性：穿透建築物較佳，城市適用 └─ 用途：市區救災、室內通訊
記憶方法VHF＝視野好的郊外，UHF＝城市裡的街道。

SDR 操作術語：用 GQRX 時會看到的
SDR（軟體定義無線電）
Software Defined Radio
傳統無線電的硬體線路（濾波器、解調器）全部改用電腦軟體來做。一個小小的 USB 接收器加上電腦就能接收各種無線電信號。
生活比喻以前每種收音機只能收一個波段（AM 或 FM）。SDR 就像一台「萬能收音機」，只要換軟體設定，就能收 AM、FM、對講機、飛機通訊、氣象衛星…什麼都收。硬體只是個「窗口」，軟體決定你聽什麼。
傳統對講機： 天線 → 固定硬體電路 → 只能做FM RTL-SDR： 天線 → ADC晶片(把電波變數字) → 電腦 電腦軟體決定：要AM？FM？SSB？ → 同樣的硬體，無限可能 RTL-SDR：電視棒改裝，約300元台幣 能接收：25MHz–1750MHz（幾乎涵蓋民用通訊）
記憶方法SDR 就是「可程式化的收音機」。硬體不變，軟體改，用途就變了。
SDR
FFT（頻譜圖）
Fast Fourier Transform / Spectrum
把「時間軸上的信號」轉換成「頻率軸上的成分」，讓你一眼看出哪些頻率有信號、強度多少。
生活比喻你在演唱會錄了一段音樂，FFT 就像音樂分析師，把這段音樂拆解成：「這裡有鼓（低頻）、這裡有吉他（中頻）、這裡有人聲（高頻）」，告訴你每個成分的「音量」。頻譜就是這個「成分分佈圖」。
GQRX的頻譜圖長這樣： 信號強度 ▲ │ ⚫ ← 對講機信號（尖峰） │ ╱█╲ │ ╱███╲ │▀▀▀▀╱─────╲▀▀▀▀▀▀▀▀ ← 底噪 └────────────────────→ 145.0 145.5 146.0 MHz 峰值越高 = 信號越強 峰值位置 = 信號頻率
記憶方法FFT 把「時間」換成「頻率」來顯示信號，就像把一首歌變成「音樂成份清單」。
SDR
瀑布圖
Waterfall Display
把頻譜圖隨時間「往下疊」，就形成瀑布圖。顏色深淺代表信號強度，讓你看到信號在時間上的變化。
生活比喻把頻譜圖印成細細的一條，然後一條一條往下疊起來。新的在上面，舊的在下面。你能看出「這個信號是什麼時候出現的」以及「持續多久」。
瀑布圖示意（時間從上往下）： 時間 145.0 145.5 146.0 MHz ↓ ───────────────────────────── t1 ░░░░░░░░░░░░▓▓▓▓▓░░░░░░ ← 有信號 t2 ░░░░░░░░░░░░▓▓▓▓▓░░░░░░ ← 繼續 t3 ░░░░░░░░░░░░░░░░░░░░░░░ ← 停了 t4 ░░░░░░░░░░░░░░░░░░░░░░░ ← 沒信號 t5 ░░░░░░░░░░░░▓▓▓░░░░░░░░ ← 又出現 深色=強信號 淺色/空白=沒有信號
記憶方法瀑布圖是「有時間軸的頻譜」，能看出信號的歷史。誰在說話、說了多久，一目瞭然。
SDR
底噪（噪聲底）
Noise Floor
即使沒有任何人發話，接收機仍然會「聽到」一些隨機的微弱雜訊，這就是底噪。是接收機能力的下限。
生活比喻你在安靜的圖書館裡，即使沒有人說話，你也能聽到空調嗡嗡聲、微弱的環境音。這就是「底噪」。任何聲音要比這個底噪高，你才能「聽到」。無線電也一樣，信號必須比底噪強，才能被接收。
FFT中的底噪與信號： 信號強度 ▲ │ ⚫ ← 對講機信號（比底噪高就能接收） │ ╱█╲ │▀▀▀▀▀╱███╲▀▀▀▀▀▀▀▀▀▀ │ ←───底噪───→ 底噪越低=越厲害 └───────────────────── RTL-SDR的底噪：約 -90 至 -100 dBm 專業接收機底噪：約 -110 至 -120 dBm
常見誤解RF 增益調太高 → 底噪也升高 → 反而遮蓋了弱信號！這是最常見的錯誤。
SDR情境2
信噪比（SNR）
Signal-to-Noise Ratio
信號強度和雜訊強度的「比值」。SNR 越高，信號比雜訊強越多，通話越清晰。
生活比喻在吵鬧的派對上，你朋友對你說話：「朋友的聲音」就是信號，「派對噪音」就是雜訊。朋友近在耳邊（SNR 高）＝聽得很清楚。朋友在房間另一頭（SNR 低）＝聽不清楚。
SNR = 信號強度 - 底噪（用dB表示） SNR 5dB以下：幾乎聽不到 SNR 10dB：勉強可懂 SNR 20dB：清晰 SNR 30dB以上：非常清晰 在GQRX的FFT中： SNR = 峰值高度 - 底噪水平 ▲ █ ← 峰值 -60dBm ███ ──────── ← 底噪 -90dBm SNR = -60 - (-90) = 30dB ← 很清晰
記憶方法SNR 就是「信號相對雜訊有多大聲」。30dB 的 SNR 意思是信號比雜訊響 1000 倍。
SDR情境2
RF 增益
RF Gain
接收機放大天線信號的倍數。增益越高，弱信號被放大越多，但雜訊也同時被放大。
生活比喻就像麥克風的音量旋鈕。聲音很小時轉大一點，確實能聽得更清楚。但轉太大了，連空氣震動都放大了，變成嗡嗡嗡的噪音。RF 增益也一樣，有個「最佳位置」。
增益與通話品質的關係： 增益 0────────────────────49.6 dB 低增益 最佳點 高增益 ┌─────┐ ┌───┐ ┌─────┐ │信號弱│ │清晰│ │噪聲大│ │聽不到│ │✓ │ │蓋信號│ └─────┘ └───┘ └─────┘ GQRX的RF Gain滑桿就在畫面左側 目標：讓SNR（差值）最大的那個增益值
常見誤解「增益設最高＝接收最好」是最常見的誤解！過高增益會讓接收機「飽和」，反而什麼都聽不到。
SDR情境2
NFM / WFM
Narrow-band / Wide-band FM
NFM 是「窄頻 FM」，用於對講機和民防通訊（12.5kHz）。WFM 是「寬頻 FM」，用於廣播電台（200kHz）。在 GQRX 中要正確選擇模式。
生活比喻NFM 像普通電話，只傳語音，通道窄，省資源。WFM 像 HiFi 音響，傳高音質音樂，通道寬。接收對講機一定要選 NFM，不能選 WFM，否則聲音會悶或聽不清楚。
GQRX模式選擇： 對講機通話 → 選 NFM，設帶寬 12.5kHz FM廣播 → 選 WFM，設帶寬 200kHz 頻道寬度對比： WFM: ─────200kHz────── （廣播電台） NFM: ────12.5kHz─── （對講機） AM: ───10kHz── （中波廣播） 調錯模式的症狀： 用WFM收對講機 → 聲音悶、低音重 用NFM收廣播 → 音質差、高頻切掉
記憶方法收對講機一律用 NFM（Narrow ＝ 窄），不然就像用望遠鏡看旁邊，焦距永遠不對。
SDR
採樣率
Sample Rate
SDR 每秒「拍照」電波狀態的次數。採樣率越高，能同時觀看的頻率範圍越寬。
生活比喻就像電影的「幀率」。24fps 的電影看起來流暢，因為每秒拍了 24 張照片。SDR 的採樣率越高，每秒收集越多「電波快照」，能分析更寬的頻段。
採樣率與可視頻段： 採樣率 1.0 MSPS → 可視1.0MHz（例：145.0–146.0） 採樣率 2.4 MSPS → 可視2.4MHz（例：144.3–146.7） 在GQRX設定採樣率後，瀑布圖的「寬度」就是你能看到的頻率範圍 建議設定： RTL-SDR：2.0–2.4 MSPS 如果CPU不夠：降到1.2 MSPS

情境參數：七大情境中的核心術語
CTCSS（亞音頻）
Continuous Tone Coded Squelch
在正常語音信號中「夾帶」一個極低頻的純音，用來控制接收機的靜噪是否開啟。38 個標準頻率，每個隊伍用一個「自己的頻率」。
生活比喻想像你和朋友說好，如果你先「清一下喉嚨」，他才開始認真聽你說話。CTCSS 就是那聲「清喉嚨」。同一個頻率上可以有很多人在說話，但只有「清喉嚨聲對上」的人，你的對講機才打開喇叭。
同一頻率145.500MHz上的多個隊伍： 隊伍A說話：語音 + 67Hz純音 → B隊（設67Hz）：打開喇叭，聽到了！✓ → C隊（設88Hz）：靜噪不開，靜音 ✗ → D隊（無設定）：所有人都聽得到 38個標準CTCSS頻率： 67.0, 71.9, 74.4, 77.0, 79.7, 82.5, 85.4, 88.5... ...最高到 250.3Hz
常見誤解CTCSS 不是「加密」！只要對方不設 CTCSS 就能聽到全部對話。這只是「喇叭開關」，不是保密工具。
情境1、4
DCS（數位亞音）
Digital Coded Squelch
和 CTCSS 相同功能，但用數位編碼（0 和 1）代替類比純音。有 104 個碼，比 CTCSS 的 38 個多，誤碼率更低。
生活比喻CTCSS 是「說一個暗號音調」（類比），DCS 是「說一串暗號數字」（數位）。兩者目的一樣：控制喇叭。DCS 更精確，但設備要相容才行。
CTCSS vs DCS 比較： 特性 CTCSS DCS 碼數 38個 104個 方式 類比純音 數位編碼 誤碼率 中 低 相容性 非常廣 需確認設備 民防推薦 ✓（更普及） 視設備而定
記憶方法C＝類比（連續音調），D＝數位（數字碼）。民防建議優先用 CTCSS，因為相容性最廣。
情境1
靜噪（Squelch）
Squelch
對講機上的一個電路，沒有信號時自動「關掉」喇叭，避免一直聽到嘶嘶聲。有信號時才開啟。CTCSS 是靜噪的一種進階控制方式。
生活比喻就像門鈴。有人按門鈴（有信號）才發出聲音，沒人按時一直保持安靜。靜噪就是對講機的「自動門鈴模式」。
靜噪的兩種控制方式： 1. 信號強度靜噪（傳統） 信號強度 > 設定門檻 → 開喇叭 信號強度 < 設定門檻 → 關喇叭（嘶嘶聲靜音） 2. CTCSS靜噪（進階） 收到正確CTCSS頻率 → 開喇叭 CTCSS不符或沒有 → 關喇叭（即使信號很強！） 在SDR中：可以看到即使靜噪關閉，FFT上仍有信號 → 靜噪只影響你「聽不聽到」，不影響信號是否存在
情境1
頻寬（Bandwidth）
Bandwidth / Channel Spacing
每個無線電頻道「佔用」多少頻率空間。民防用 12.5kHz（窄頻），舊設備用 25kHz（寬頻）。頻寬窄＝每個頻道佔地小＝同段頻率可放更多頻道。
生活比喻把頻率範圍想成一條公路。25kHz 頻寬就像佔了兩個車道，12.5kHz 只佔一個車道。用窄車道就能放更多車（頻道），其他車也不容易撞到你（干擾少）。
相同頻段放多少頻道： 144–148MHz（4MHz可用） 使用25kHz：4000kHz ÷ 25kHz = 160個頻道 使用12.5kHz：4000kHz ÷ 12.5kHz = 320個頻道 → 窄頻讓頻道數量加倍！ GQRX中的視覺差異： 25kHz： ─────█████████───── （寬山型） 12.5kHz：──────████─────── （窄尖型）
記憶方法12.5＝窄頻＝現代標準＝省空間。25＝寬頻＝老式＝佔空間。民防統一用 12.5kHz，才能和更多隊伍溝通。
情境3
天線 / λ/4 天線
Antenna / Quarter-wave
天線把電能轉換成電磁波（發射），或把電磁波轉換成電能（接收）。最簡單有效的是四分之一波長天線（λ/4），長度是頻率波長的 1/4。
生活比喻天線就像音叉。音叉的長度決定它振動的頻率（音調）。天線的長度決定它最有效率地「振動」哪個頻率。長度不對的天線就像一把走音的吉他。
如何算你的對講機天線應該多長： 波長 = 300 ÷ 頻率(MHz) λ/4天線長度 = 波長 ÷ 4 145MHz VHF對講機： 波長 = 300 ÷ 145 = 2.07m λ/4 = 2.07 ÷ 4 ≈ 51.7cm 435MHz UHF對講機： 波長 = 300 ÷ 435 = 0.69m λ/4 = 0.69 ÷ 4 ≈ 17.2cm 應急情況下可用電話線自製天線！
常見誤解天線方向也很重要！垂直極化的天線要豎起來，不能橫放。橫放可能損失 10dB 以上（＝信號強度減少 10 倍）。
情境5
中繼台 / 雙工
Repeater / Duplex
中繼台放在高點（山頂、大樓屋頂），接收一個頻率，立刻用另一個頻率轉發出去，讓兩側的隊伍能通過中繼台互相通話。雙工就是「一邊收一邊發」。
生活比喻你和朋友之間有一座山，直接講話對方聽不到。你在山頂放一個「傳話機器人」，你說一句，機器人立刻用大喇叭廣播出去。「雙工」就是這個機器人同時用耳朵聽和嘴巴說，要用不同頻率否則會「迴音」。
中繼台頻率對（Offset）： 隊伍A 發145.500 ──→ 中繼台接收145.500 ↓（立即轉發） 隊伍B 收146.100 ←── 中繼台發射146.100 設定方式（在對講機上）： 頻率：145.500（你「說」的頻率） 偏移：+600kHz = 自動接收145.500+0.600=146.100 為什麼收發要不同頻率？ 同頻率 → 自己說話自己聽到 → 產生嘯叫聲
記憶方法中繼台＝山頂傳話員，雙工＝分開「嘴巴」和「耳朵」的頻率，避免迴音。
情境7
靈敏度
Receiver Sensitivity
接收機能聽到的「最微弱的信號」。靈敏度越好（數字越小），越遠的對講機你也能聽到。
生活比喻在黑暗中，有人能看到 1 公里外的蠟燭，有人只能看到 100 公尺內的。看得到 1 公里外蠟燭的眼睛，就有更好的「靈敏度」。
靈敏度的單位是dBm（越小越好）： 普通對講機靈敏度：-100 dBm 好的接收機靈敏度：-120 dBm RTL-SDR靈敏度： 約-90 至-100 dBm 影響靈敏度的因素： ✓ 頻寬（窄 → 靈敏度好） ✓ 接收機品質（雜訊低 → 靈敏度好） ✓ RF增益設定（適當 → 靈敏度好） ✗ 環境溫度高 → 靈敏度變差
記憶方法靈敏度就是「耳力」，數字越小（負越多）＝耳力越好。
情境2
干擾 / 捕捉效應
Interference / Capture Effect
干擾是指不相關的信號破壞你的通訊。FM 特有的「捕捉效應」是：當兩個信號在同一頻率上，FM 接收機傾向只接收「更強的那個」，較弱的信號被「壓制」。
生活比喻想像兩個人同時對你大喊話，一個離你很近（強），一個離你很遠（弱）。FM 的捕捉效應讓你只關注近的那個人。但如果干擾者的信號比你的指揮官更強，你就只聽到干擾者了！
FM捕捉效應： 情況1：我方信號強（乾淨通話） 我方 ─────████─────── S7（較強） 干擾 ─────███──────── S4（較弱） 結果 → 只聽到我方 ✓ 情況2：干擾信號更強（被壓制） 干擾 ─────████─────── S7（較強） 我方 ─────███──────── S4（較弱） 結果 → 只聽到干擾 ✗ ← 緊急換頻！
常見誤解干擾不是「有人故意搞你」，可能只是附近的工業設備、舊式電台、甚至相鄰頻道洩漏。先掃頻確認再行動。
情境6
進階理論：深入理解的關鍵概念
dB（分貝）
Decibel
一種「倍數」的表示方式，用對數把超大或超小的數字壓縮成好記的數字。無線電領域中到處都用到。
生活比喻人聲最小（耳語）是 0dB，搖滾演唱會是 110dB。如果用直線計算，演唱會比耳語響 1 千億倍。dB 讓這個巨大的數字變成可以寫在黑板上的「110」。
dB的直覺感受（功率）： +3dB = 功率變為2倍（幾乎感受不到） +6dB = 功率變為4倍（稍微大聲） +10dB = 功率變為10倍（明顯更強） +20dB = 功率變為100倍（強很多） +30dB = 功率變為1000倍 反向： -3dB = 功率剩一半 -10dB = 功率剩十分之一 -20dB = 功率剩百分之一
記憶方法+10dB ＝ 10 倍功率，+3dB ≈ 2 倍功率。這兩個數字記住，其他都可以推算。
進階
駐波比（SWR）
Standing Wave Ratio
衡量天線和電纜「配合度」的數字。SWR=1 是完美，SWR 越高代表越多能量被「反射回來」而浪費掉，沒有真正發射出去。
生活比喻想像你用水管澆花，水管有個彎折處（天線和電纜接頭不匹配）。一部分水能出來澆花（信號發出），一部分被擠回來（反射能量）浪費了。SWR=1 就是水管筆直，完全沒阻礙。
SWR判讀標準： SWR 1.0 完美匹配（理論值） SWR 1.0–1.5 優良 ✓（通訊設備標準） SWR 1.5–2.0 可接受（輕微損失） SWR 2.0–3.0 需要調整（10–25%功率損失） SWR 3.0以上 嚴重問題 ✗（天線可能損壞） SWR 無限大 開路（天線斷了）或短路
進階情境5
菲涅耳區 / 視距
Fresnel Zone / Line of Sight
無線電信號不只走「直線」，它的能量分布在一個橢圓形的「管子」裡（菲涅耳區）。如果這個管子被山丘或建築物擋住，信號就會嚴重衰減，即使你「看得到」對方。
生活比喻水管裡的水不只在管子中心流，靠近管壁的水流也很重要。無線電的「菲涅耳區」就是這個能量分布的「管子」。山丘如果超過這個管子半徑高度，信號就受到嚴重影響。
為什麼「看得到」但還是收不到： 你 ─────────────────── 對方（直線距離3km） ↑山丘（60公尺） 145MHz電波的菲涅耳區半徑（中點）：≈ 39公尺 山丘超過39公尺 → 進入菲涅耳區 → 信號損失嚴重 解決方案： ✓ 在山丘上架設中繼台 ✓ 移動到更高的位置 ✓ 換用更低頻率（菲涅耳區越小）
進階情境7
互調干擾（IMD）
Intermodulation Distortion
當兩個強信號同時進入接收機時，接收機內部的非線性元件會產生「假信號」在其他頻率上，造成莫名其妙的干擾。
生活比喻你的麥克風同時收到兩個樂器的聲音，音響系統產生了這兩個頻率「相加減」的新音調，即使沒有人演奏那個音。這個「幻影音」就是互調干擾。
互調干擾的計算： 兩個信號頻率 f1=145.500MHz, f2=146.000MHz 產生虛假信號： 2×f1 - f2 = 145.0MHz ← 假信號！ 2×f2 - f1 = 146.5MHz ← 假信號！ 解決： 降低RF增益（讓接收機不過載） 加裝帶通濾波器
進階情境6
路徑衰減
Path Loss / Free Space Loss
無線電信號從發射天線出發，隨著距離增加而自然「擴散變弱」。即使沒有任何障礙物，距離加倍，信號強度也會剩約四分之一。
生活比喻你拿手電筒在空曠地方照射，光束越走越散。在 1 公尺處非常亮，在 10 公尺處同樣的光就散開很多。無線電信號也一樣，距離越遠，「每平方公尺收到的信號」就越弱。
距離與信號衰減（自由空間）： 每倍距離 → 信號衰減約6dB（= 強度剩1/4） 100m → 參考基準 200m → 弱 6dB（約原來1/4） 400m → 弱12dB（約原來1/16） 800m → 弱18dB（約原來1/64） 1600m → 弱24dB（約原來1/256） 這就是為什麼：2km還能清晰，4km突然很難通話
進階情境2
天線增益 / dBi
Antenna Gain / dBi
天線把電能「集中」到某個方向的能力。增益越高，方向性越強，那個方向的信號越強，但其他方向變弱。
生活比喻手電筒的燈泡發出的光是向四面八方（低增益天線）。加上反射鏡後，光全都集中在一個方向，前方非常亮（高增益天線）。dBi 是衡量它比全向天線強多少的單位。
常見天線增益： 類型 增益 方向性 全向鞭天線 0–2dBi 無方向（手持、車載） 車頂磁吸天線 3–5dBi 輕微（移動通訊） 基地台天線 6–9dBi 垂直面（中繼、固定站） 八木天線 10–15dBi 強方向（點對點） 拋物面天線 20+dBi 極強方向（衛星） 增益越高：該方向更遠，但必須精確對準
